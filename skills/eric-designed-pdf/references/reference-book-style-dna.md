# Reference Book Style DNA

Use this reference when Eric asks for Cambridge-style, In Use-style, National Geographic / GIC-style, self-study reference-book, student book, or formal English textbook design. This file records abstract page grammar only. Do not copy logos, passages, exercises, images, screenshots, exact spreads, or full-page layouts from reference books.

## Source Boundary

- Reference PDFs can teach page roles, density, hierarchy, color behavior, and exercise progression.
- They cannot be treated as templates to clone.
- Keep all instructional text selectable/searchable in HTML/Typst/PDF, not baked into page images.
- Use original or licensed visuals; never reuse reference-book artwork or photography.
- In project notes, say "abstracted from professional reference-book grammar", not "copied from Cambridge/NatGeo".

## Three Useful Families

### 1. In Use Vocabulary Rhythm

Use for lexical IELTS topics, speaking chunks, listening form words, paraphrase banks, and useful phrase pages.

- Pair explanation and practice: a teaching/reference page followed by a practice page, or the A4 equivalent on consecutive pages.
- Presentation page: topic title, section letters, small semantic groups, target words in bold, short bracket glosses, labeled image clusters or compact diagrams when vocabulary is visual.
- Practice page: numbered sub-exercises that progress from recognition to controlled use to personal output.
- Exercise surfaces stay calm: teal section numbers, concise instructions, stable answer lines, compact word boxes, one final "Your Turn" communicative task.
- Avoid one giant word list. Vocabulary should appear inside mini contexts, labeled groups, example sentences, or images.

### 2. In Use Grammar Rhythm

Use for grammar or sentence-accuracy pages in IELTS writing/speaking foundations.

- Reference page: strong unit title band, one grammar contrast, A/B/C/D sections, situation or mini story first, then rule language.
- Explain with examples before terminology. A small illustration or scenario can anchor the difference, but text remains the main learning layer.
- Use pale tinted panels for explanation blocks; keep examples close to the rule they prove.
- Add tiny cross-reference or reminder strips only when useful; do not turn them into dashboard navigation.
- Exercise page: large "Exercises" role, small exercise labels, long dotted/writing lines, one grammar target per exercise, and clear movement from guided transformation to free sentence production.

### 3. National Geographic / GIC Student-Book Rhythm

Use for student-book pages that need more life: reading, listening context, unit openers, real-world topic pages, and communicative grammar.

- Real-world image first when the page role needs context: photo-led reading, campus/life scene, place, object, or human activity.
- Image must teach context, not decorate. Pair it with a passage, question set, grammar use box, or personal speaking task.
- Use editorial callouts and thin rule lines to point to features; do not make app-like cards.
- Grammar or vocabulary tables can be wider and more direct than handbook pages, but they still need a clear learner action beneath them.
- End with personalization: a short prompt that lets the student use the language for their own life, opinion, study situation, or IELTS answer.

## IELTS A4 Adaptation

For IELTS first-month or first-week packs, do not imitate book trim spreads literally. Translate the spread logic into A4 page sequence:

1. Know: explain one learnable point.
2. See: show 2-4 model examples or a short situation.
3. Try: give a controlled exercise with stable answer lines.
4. Use: ask for a short spoken/written output that connects to IELTS.

Good page pairs:

- Listening answer types -> form-filling mini task.
- Speaking expansion -> one-sentence answer -> three-sentence answer.
- Sentence core -> subject/verb spotting -> sentence rewrite.
- TRUE/FALSE/NOT GIVEN -> evidence line examples -> short question set.
- Useful chunks -> grouped phrases -> personal answer practice.

## Page Contracts

### Reference Page

Must include:

- one clear title naming the learnable point
- a short situation or problem
- explanation in learner language
- 2-4 model examples
- compact rule/table
- quick check
- remember / watch out strip

It may include small practice, but practice cannot be the page identity.

### Practice Page

Must include:

- numbered exercise groups
- concise instructions
- answer spaces aligned to the task
- progression from recognition to production
- one final transfer prompt when appropriate

It should not become a loose list of questions.

### Photo / Context Page

Must include:

- one real-world visual with manifest evidence
- text/task that needs the visual
- one short reflection, speaking, or evidence task

It should not use a generic pretty study image when the topic needs a real object, place, process, or learner situation.

## Acceptance Checklist

Before visual scoring, check:

- Does the contact sheet show reference pages paired with practice pages?
- Does each knowledge page teach enough for a student to study alone?
- Are exercises progressing from easier recognition to harder production?
- Are images tied to reading/listening/speaking context rather than decoration?
- Are Chinese notes short learner hints, not long teacher explanations?
- Does the result feel like a printed English textbook, not a worksheet packet, dashboard, or AI-generated course map?

## Reject Labels

- `reference-book-dna-missing`: the user asked for Cambridge/In Use/NatGeo/student-book style, but pages remain generic handouts or isolated worksheets.
- `spread-pairing-missing`: knowledge and practice are not paired; the student gets explanation without use, or exercises without enough reference support.
- `reference-density-weak`: self-study pages lack explanation, examples, rule/table, quick check, or remember strip.
- `image-as-decoration-drift`: a large image is attractive but does not support the reading/listening/speaking/grammar task.
- `copycat-reference-book-risk`: the design too closely mirrors a named reference book's brand, original content, imagery, or exact page layout.
