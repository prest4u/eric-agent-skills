# Component Grammar

Use this reference when mapping content into page templates.

## Required Components

Each sample or new system should exercise these components unless the user narrows the scope:

- `cover`: full-bleed book identity, no visible production notes; bottom-right `Eric Teaching Studio` brand mark; no course-stage/level badge in the cover top-right corner.
- `title-page`: book title, subtitle, level, edition/sample status; whitespace must still feel intentional.
- `title-navigation`: quiet rows or unit map that make p2 useful without turning it into a dashboard; custom mixed-language titles may use a `title-single` lockup while English sample titles can keep an editorial stack. For single-lesson Chinese packs, allow an explicit `cover_title_lines` / editorial title metadata so the cover can use a deliberate two-line concept lockup instead of a flat one-line title.
- `single-lesson-cover-lockup`: Chinese single-lesson covers need the lesson concept as the first signal with strong modern sans title weight. `cover_title_lines` is only the structure; the rendered typography must also avoid thin/default CJK serif drift and be strong at contact-sheet size. Long concepts with `：`, `、`, `_`, or `与` need generator-level editorial lines and a long-title scale; do not let the browser wrap them or use the same huge second-line size as short titles.
- `unit-opener`: photo, unit number/title, contextual prompt.
- `objectives-band`: compact objectives in a colored band. If the opener has a pre-unit prompt such as `Before the unit begins...`, place it inside the band as an opener prompt, not as floating text over the image edge.
- `elements-page`: rule explanation plus example table.
- `activity-block`: magenta label, activity number, task instruction.
- `word-box`: bounded vocabulary choices for controlled practice.
- `words-to-know`: small vocabulary support block.
- `workbook-practice`: cohesive record surface with a header, numbered prompts, and stable writing lines; this is the activity-page writing affordance, not loose trailing Q&A lines.
- `paragraph-practice`: model/practice paragraph with paper texture.
- `writing-run`: when a lesson has consecutive writing pages, use a process sequence rather than repeated blanks: task/idea planner, draft paper, and final copy or revision/check page.
- `photo-passage`: image, caption, short response prompts.
- `mechanics-table`: rule or sentence-part table.
- `study-reference`: learning-handbook/reference page for student self-study. It should combine explanation blocks, model examples, a compact rule/table, a small quick check, and a remember strip. Use it when the student must be able to learn from the PDF without the teacher present; do not substitute planner rows, review logs, or fill-in-heavy workbook pages for this role.
- `reference-practice-pair`: A4 adaptation of professional reference-book spreads. Put a knowledge/reference page before its matching practice page, or combine them only when the page still has clear Know -> See -> Try -> Use movement. Use for Cambridge/In Use-style grammar, vocabulary, and IELTS foundation pages.
- `personal-output-box`: short final transfer prompt where the learner uses the language for their own IELTS answer, opinion, campus/study situation, or daily life. It should close a practice sequence, not replace the explanation.
- `writing-planner`: structured prewriting rows with stable lines inside a tactile paper-surface block; use a small rule strip, editorial side labels, and softer prompt text so the page does not read as a spreadsheet or progress tool.
- Repeated planner/final-check families must choose a real rendered surface, not just a new title: Task 2 answer pages can be agree/disagree ladder, discussion bridge, problem/solution matrix, advantage balance sheet, or full mock booklet; listening reviews can be form ledger, map path, speaker-opinion matrix, or lecture-note columns; reading closes can be line evidence, paraphrase pairs, or transfer ticket.
- Repeated review/categorizing close pages need the same rule. 匿名热区, 私人自检, course-route planning, and final check pages may share a family, but they must not share one visible grid with renamed rows. Use heat/error-bank cards, route/index rows, review ledger, and action ticket surfaces according to the teaching role.
- `editing-checklist`: checkbox-style final review.
- `final-action-ticket`: single-lesson and unit-close pages need a final learner action surface, usually `下一次行动` / exit ticket with 2-3 concise prompts and stable writing lines. This prevents review/final-check pages from ending as thin forms with dead lower-page space.
- `handbook-page`: back-matter lookup/reference page with pale field, a compact meta band, numbered index rows, quiet section labels, mini rules, and denser table rhythm.
- `handbook-page` tables that include student-fillable blank cells need visible writing affordance. Empty reference-table cells should not render as plain empty `td` boxes; add lower writing rules or dedicated lines so the page reads as a usable workbook/reference page. Match selectors to the actual renderer output, for example `table[data-component="handbook-table"]`, rather than assuming `data-component` is also a CSS class.
- `answer-key-page`: teacher/back-matter answer lookup. Prefer grouped compact answer blocks with a meta band and notes over one long plain table.
- `teacher-guide-page`: teacher-only classroom guide pages with lesson flow, page-by-page teaching notes, likely errors, correction moves, board notes, and close checks. Do not render Teacher Guide content through `teacher-answer-key`.
- `teacher-page-note`: teacher-profile margin note on the student-equivalent page. It should tell the teacher how to run that page, not repeat generic production-script wording.
- `teacher-answer-strip`: compact teacher-only answer/evidence strip on the matching practice page. It keeps the teacher book runnable without forcing the teacher to flip to the back for every question.

## Student-Book Form Components

Use these when a project should absorb professional student-book form, especially for 中高考 / 高二升高三 grammar or reading courses:

- `section-ribbon`: yellow/warm top ribbon or quiet section marker for Reading, Grammar, Vocabulary, Review, or Handbook pages.
- `skill-side-label`: small left-side cognitive label such as 位置, 缺成分, 逻辑, 回填, Main Idea, Detail, Inference, Categorizing.
- `article-title-lockup`: large editorial title plus compact subtitle/category; use with an anchored visual or evidence field.
- `lettered-paragraph`: A/B/C paragraph groups for reading flow, concept story, or worked explanation.
- `vocab-highlight`: deterministic inline highlight for grammar terms, connector choices, or vocabulary; never baked into an image.
- `definition-footnote`: compact definition/support line near passage text.
- `guided-mcq-set`: MCQ block with task label and stable answer spacing.
- `exam-stem-slot`: MCQ/cloze question-stem blanks use a dedicated `.exam-stem-slot` and `.exam-stem-keep` renderer, not generic `.blank` and not writing lines. This keeps punctuation attached and keeps short slots on the sentence baseline.
- `categorizing-chart`: small table for evidence/error grouping; should read like textbook practice, not a dashboard.
- `sentence-map-card-stack`: A4 long-sentence analysis surface with stacked sentence / analysis / check fields. Do not force long sentence maps into a wide three-column table on A4.
- `critical-thinking-strip`: colored transfer/reflection strip with short response lines.
- `diagram-callout`: labeled map/tree/grid for sentence structure, clause boundary, or logic relation.
- `practice-word-box`: compact no-wrap choice bank.
- `unit-folio`: quiet page/unit marker.

## Content Mapping Rules

- One source page lives in `pages/*.md` with frontmatter selecting `template`.
- Book order lives in `book.yaml`; avoid hidden ordering inside filenames alone.
- Images must be referenced by asset id from `assets/manifest.json`, not ad hoc file paths.
- One visual asset is one page-role use. Do not reuse one asset id across pages, do not make two asset ids point to the same image file, and do not reuse the cover image inside the book. Add `allowed_templates` to each visual asset; use `["cover"]`, `["unit-opener"]`, or `["photo-passage"]` as appropriate.
- Final cover, unit-opener, photo-passage, context, and hero images require `qa.asset_mode: final-assets` and manifest evidence: `kind: imagegen` or licensed/owned original, approved final status, prompt/source note, focus, allowed template, real-world scene anchors, and a no-visible-text/no-questions/no-answers text policy. Prefer nature, landscape, wildlife, or realistic animal photographs when suitable; use campus/classroom/library/study or modern human learning/life scenes when those fit better, and then record `family_rationale` or `nature_first_rationale` so QA knows why the second family was chosen. Final cover/hero assets also require `content_brief`, `visual_direction`, and `uniqueness_note`; design the image from the actual lesson/book content and avoid generic, reused, or abstract-symbolic template cover art.
- Custom projects must replace starter sample identity across `book.yaml`, pages, manifest, renderer labels, Typst labels, and output names; `STARTER_RESIDUE_FOUND` blocks release.
- Student profiles should exclude answer-key pages unless the user explicitly requests a student-visible key.
- Teacher-only wording belongs in teacher routes or internal notes, never in student-visible pages.
- A real teacher edition must not be only a student book followed by appended answer tables. Unless Eric explicitly asks for appendix-only mode, teacher profiles need integrated teacher notes/answer strips on relevant student-equivalent pages plus separate `teacher-guide-page` reference pages. `Teacher Guide` rendered as `teacher-answer-key` is `TEACHER_BOOK_APPENDIX_ONLY_DRIFT`.
- Student-visible wording should describe learner actions, not production workflow; rewrite `Route`, `主动作`, `Repair`, `维修`, `路由`, `后台`, or `闭环`.
- Premium 中高考 workbook/student-book pages need a visible-title layer. Keep source/course titles in data, but render page-role headings as workbook English where appropriate: `Lesson Map`, `Quick Check`, `Detail Evidence Model`, `Writing Moves`, `Writing Practice`, `Review Check`, `Review Record`, `Error Pattern Check`, and `Next Practice Plan`. Avoid English-but-AI labels such as `Lesson Route`, `Lesson Rhythm`, `Practice Rhythm`, `Micro Skills`, `Anonymous Error Hotspots`, and `Personal Check And Course Plan`. Reading passage/article titles and reading question-set headings must be English; map Chinese source titles to neutral English article titles before writing `article-opener` or reading `exam-mini-set` pages.
- For student-book conversions of Chinese exam lessons, map source blocks before page writing: lesson route -> title navigation; quick diagnostic -> comprehension/check page; core model -> skill/method page; think-aloud -> model sentence and record rows; classified drill -> grammar practice page; mixed timed drill -> review page; reading transfer -> article/inset evidence page; writing correction -> workbook/planner surface; rule summary -> handbook lookup page.
- For writing blocks with multiple pages, do not generate `writing 1/3`, `2/3`, `3/3` as identical paragraph-practice pages. Choose a visible writing process: plan the task and points, draft on full writing paper, then revise/check or prepare final copy.
- For single-lesson Chinese exam packs, the lesson map is not a full-book table of contents. Render it as a classroom route surface: numbered anchors, soft paper field, compact task/scope rows, and no dense page-index grid unless the artifact is truly a whole-book contents map.
- Single-lesson cover and title-page H1 must share the same explicit title-line metadata. If the cover uses `cover_title_lines` but the title page calls the markup helper without those lines, p2 will squeeze long lesson concepts into a document-like H1; treat that as `single-lesson-title-page-wrap-drift`.
- A grammar/practice book should not remain a long numbered list. Use A/B/C exercise sections, word boxes, categorizing charts, skill labels, and back-matter lookup rhythm to create page-role contrast.
- A self-study learning handbook should not be a disguised workbook. If Eric says the student should "拿着自己学习" or "有很多知识点", use `study-reference` pages as the core rhythm and let practice pages connect to class tasks only after the explanation is clear. A contact sheet dominated by records, planners, checklists, or empty writing lines is `self-study-handbook-drift`.
- If Eric mentions Cambridge, In Use, National Geographic, GIC, or similar textbook references, read `reference-book-style-dna.md` and map the material into abstract textbook grammar: reference/practice pairs, A/B/C section rhythm, compact tables, real-world visual context, and a final personal-response activity. Do not clone reference-book brands, text, photos, or exact layouts.
- If a reference PDF is raster-only, do not mirror that production structure. Preserve deterministic HTML/Typst text layers even when the reference looks like a whole-page image book.
- Mixed Chinese/English cover titles and student names must be locked deliberately; never let the browser split a word or orphan a name suffix.
- If a mixed Chinese/English title is still one book title, keep all title parts at the same optical scale and weight. Do not shrink a `for Sample Learner` / student-name suffix inside the same H1; either use a same-scale single-line lockup or move the suffix to a real subtitle/meta line.
- Cover stage metadata such as `高二升高三`, `Level 1`, or `Student Book` should not appear as the top-right cover badge. Put `Eric Teaching Studio` in the bottom-right cover brand position, and give `.cover-brand` enough contrast protection to remain readable over real photos; keep level/stage information for title/navigation pages or quiet subtitles.
- Avoid duplicate Studio wordmarks on final covers. The required Studio mark belongs bottom-right; the top cover mark may be icon-only or carry a non-duplicative quiet series label. Repeating `Eric Teaching Studio` at both top and bottom is `cover-double-branding`.
- Inline exercise blanks should sit visibly near the lower writing baseline/lower edge of the line box; a centered underline or literal underscore run in any visible exercise text is `floating-blank-line` and should be repaired before visual review. Treat the older global `-0.64em/-0.68em` alignment as too high for release. Model-note / paragraph-practice body blanks are cloze blanks, not full writing lines; use `.paragraph-practice p .blank { vertical-align: -0.22em; }` so the short underline sits with the serif paragraph text and does not dangle below the line. Workbook-record prompt blanks are also cloze blanks; use `.record-prompt .blank { vertical-align: -0.32em; }` so prompt text does not look broken by a dropped answer line. Ordinary inline cloze blanks inside activity instructions/items, word boxes, words-to-know, table cells, review rules, planner prompts, editing checklist labels, handbook rows, and answer tables must use the inline cloze context group with `vertical-align: -0.30em`; otherwise they can drop like answer lines even though they are technically `.blank`.
- Keep punctuation attached to a preceding blank. Author text such as `____.`, `____,`, `____。`, or `____，` should render as one `.cloze-keep` no-wrap visual unit so punctuation does not orphan onto its own line.
- Narrow phrase blanks need a stricter rule. Word boxes, mini-rule cards, captions, sidebars, compact lookup rows, and narrow table/checklist cells should not show a blank as a standalone underline. Use `.cloze-keep` to bind the preceding word, blank, and punctuation; use `.word-box-item { white-space: nowrap; }` so a phrase such as `quickly ____ sold` stays together; use compact slots (`.word-box .blank { vertical-align: -0.26em; }`, `.handbook-rules .blank { vertical-align: -0.24em; }`) rather than full writing-line blanks. In reference mini rules, prefer copy without blanks unless the card is explicitly a practice prompt.
- Question prompts with dedicated writing lines must not also render inline cloze blanks. For `.question-lines li`, remove author placeholders with `prompt_text_before_write_lines()` before appending `.write-line`; a prompt item containing both `.blank` and `.write-line` is `question-line-double-blank` and must fail `QUESTION_INLINE_BLANK_WITH_WRITE_LINE`.
- MCQ and cloze stems are a separate blank type from writing lines and inline workbook cloze blanks. In `.guided-mcq-set p`, render author `____` placeholders as `.exam-stem-slot`; bind punctuation after the slot with `.exam-stem-keep`; never allow `.guided-mcq-set p .blank`. This prevents the recurring exam-stem underline drift where the line floats high, drops low, or detaches from punctuation.
- A4 `sentence-map` pages must use a stacked card surface with `data-surface-family="sentence-map"` and a real `data-surface` marker. A three-column long-text table is acceptable only when the content is genuinely short and not in A4 lesson-pack mode.
- Label-prefixed planner/check prompts with dedicated writing lines should normally avoid short inline blanks before long prose, such as `Connector: ____ Evidence: ...`. The blank can become visually weak even when the HTML is technically correct. Prefer prompt text plus the row's write lines; label weak or missing-looking short slots as `planner-label-blank-weak`.
- Editing checklist controls must use explicit marker classes (`.check-mark`) rather than generic descendant selectors such as `.editing-checklist label span`. Text-bearing components may contain `.blank`, emphasis spans, captions, icons, or title fragments; styling all spans is `control-selector-leak`.
- Rendered PNG text is the visual source of truth for glyph quality; apply `rendered-text-glitch` when punctuation, apostrophes, ranges, or mixed CJK/Latin text look wrong even if extracted text is correct.
- When `diagnostic-form-drift` appears, repair the whole page role: soften tool-like labels, shorten prompt strips, make activity pages read as model + practice record, make final-check pages use a real thinking strip/exit ticket, make planner instructions an understated rule strip, and increase handbook/answer-key lookup density. Do not only tune CSS.
- When `scorecard-tool-drift` appears, do not rename only the title. Reframe the page as textbook work: lesson preview, evidence check, method focus, practice set, opening notes, or before-you-leave review. Student-visible 中高考 lesson packs must not sell the work as `动作卡`, `自检卡`, `得分动作`, `score moves`, `scorecard`, or `self-check card`.

## Failure Modes

- **Generic worksheet look:** add textbook rhythm: top rule, activity label, rule table, varied page roles.
- **Raster book drift:** text-heavy output is hidden in images or exported as full-page rasters. Rebuild with deterministic text; images may only carry context/visual signal.
- **Article form missing:** article/concept opener has only a large title and paragraphs. Add an anchored visual/evidence field, lettered paragraph rhythm, inline keyword highlights, and small support notes.
- **Skill ribbon missing:** skill/practice pages lack section ribbons or cognitive side labels. Add the ribbon/label system before visual scoring.
- **Exercise taxonomy flat:** practice is a plain numbered list. Split into A/B/C task types, add word-box/categorizing/chart surfaces, and vary page roles.
- **Backmatter index weak:** handbook pages lack lookup density. Add compact rows, glossary/index rhythm, and quiet table hierarchy.
- **Self-study handbook drift:** a requested learning handbook is built mostly from workbook/log/planner templates. Rebuild around `study-reference`: explanation blocks, examples, compact rule tables, quick checks, remember strips, and only small controlled practice where it proves understanding.
- **Reference-book DNA missing:** a requested Cambridge/In Use/NatGeo-style artifact still looks like generic handouts. Rebuild around `reference-practice-pair`, `study-reference`, section-letter rhythm, controlled-to-personal exercise progression, and real context visuals when the page role needs them.
- **Stacked opener / floating prompt:** opener pre-unit copy floats above the Objectives band and can overlap the band edge. Move it into the objectives band as `.opener-prompt` and keep the opener as one controlled composition.
- **Overfilled page:** split into another page; do not shrink text until it feels like a spreadsheet.
- **Long chart row overflow:** split `categorizing-chart` pages by longest row text, not only by row count. Reading/writing charts with long rows should drop from five rows to four or three rows before CSS shrinking.
- **Empty-looking page:** add a functional element such as word support, question lines, checklist, or mini table.
- **Empty title page:** add restrained navigation rows or a unit map; do not fill it with decorative UI blocks.
- **Loose workbook tail:** replace scattered activity questions/lines with a `workbook-record` surface: record header, numbered row labels, concise prompts, and bounded writing lines.
- **Plain planner table:** add a paper-surface wrapper, quiet rule strip, softer prompts, editorial side labels, and stable writing lines. Avoid blocky UI labels; the left planner column should feel like printed marginalia.
- **Thin lesson close surface:** add a final learner action ticket after the review/check record; do this in the template/generator so every independent lesson closes with a real workbook activity rather than one sparse table.
- **Lesson map table drift:** replace full-book index or two-column list residue with a lesson route paper surface and compact scope rows; avoid making the first route page feel like a dashboard or cropped contents page.
- **Metadata-only variant:** if two pages have different `variant:` values but the same rendered grid, row language, and `data-surface`, rebuild the renderer branch before changing CSS.
- **Floating blank line / orphan slot line:** convert `___` / `______` author text in paragraphs, questions, instructions, word-box items, activity items, tables, planner prompts, and checklist lines into `.blank`, use the zero-height bottom-rule model, remove upward transforms, lower exercise blanks to the lower-edge writing baseline (`-0.82em`; `-0.88em` inside question lists), add the paragraph cloze override (`.paragraph-practice p .blank { vertical-align: -0.22em; }`) so model-note blanks read as inline cloze spaces rather than dangling writing rules, add the record-prompt cloze override (`.record-prompt .blank { vertical-align: -0.32em; }`) for workbook-record prompts, add the inline cloze group override (`vertical-align: -0.30em`) for activity instructions/items, word boxes, tables, review rules, planner prompts, checklist labels, handbook rows, and answer tables, and add compact no-wrap phrase rules for word-box choices / handbook mini rules so blanks do not become lonely horizontal rules in narrow cells.
- **Question-line double blank:** if a numbered question has full writing lines below it, do not keep the author `____` as a visible inline blank. Strip it with `prompt_text_before_write_lines()` or remove the full writing line; the combined affordance is visually noisy and is blocked by `QUESTION_INLINE_BLANK_WITH_WRITE_LINE`.
- **Planner label blank weak:** if a planner/check prompt uses `Label: ____` before long explanatory text and the blank is visually weak, remove the inline slot and let the dedicated writing lines carry the answer.
- **Broken cover title:** reduce size, widen the text area, or set a deliberate editorial line break; do not accept accidental wrapping.
- **Mixed title scale drift:** if a title suffix or student name is smaller inside the same H1, restore same-scale same-weight lockup or make that text an actual subtitle.
- **Control selector leak:** replace generic `label span` / `.row span` control styling with explicit marker classes, then verify content blanks inside checklist/table/sidebar cells still render as blanks rather than rectangles.
- **AI/backstage wording:** run the visible-language pass and extracted-PDF scan before visual review.
- **Visible title AI language:** if page headings show raw Chinese workflow labels such as `路线`, `微技能训练`, `段落诊断`, `作业说明`, or `复盘记录`, add/repair the visible-title map in the generator. If reading article/set headings are Chinese, apply `reading-title-language-drift` and regenerate.
- **Manifest unused asset drift:** independent lesson packs should not inherit full-course manifest assets they never use. Filter manifest entries to actual asset refs and keep every manifest path real.
- **Starter residue:** remove sample book titles, `English Writing System`, starter canyon assets, and starter paragraph titles from custom sources before build/review.
- **Image carrying text:** recreate text as HTML/Typst and use the image only as visual context.
- **Proof image shipped as final:** switch to `final-assets`, generate or license real visuals, update manifest metadata, rebuild, and rerun QA.
- **Generic cover art:** write a content-specific `content_brief`, `visual_direction`, and `uniqueness_note`, then generate a cover concept that belongs to this lesson/book rather than a reusable pretty study image.
- **Abstract asset drift:** if ImageGen produces paper sculptures, symbolic boards, token maps, floating strips, or a concept-art object that is hard to understand, regenerate first as realistic nature, landscape, wildlife, or animal imagery when suitable; otherwise use campus/classroom/library/study or modern human learning/life imagery and rerun `FINAL_ASSET_UNINTERPRETABLE_SCENE`.
- **Cover image reused inside:** create separate unit opener / photo passage / context assets with separate image files and `allowed_templates`; rerun `ASSET_REUSED_ACROSS_PAGES`, `COVER_ASSET_REUSED_INSIDE_BOOK`, and `ASSET_PATH_REUSED_IN_MANIFEST`.
- **Cover brand drift:** restore `Eric Teaching Studio` to the bottom-right `.cover-brand`; add contrast protection when it sits over a real photo; remove top-right level/stage badges from the cover.
- **Cover double branding:** keep the bottom-right Studio brand and remove or weaken the top text mark when it repeats the same words.
- **Back matter too plain:** use pale field, a top meta band, numbered lookup rows, mini rules, compact index rows, quiet section labels, and a dense reference table rhythm.
- **Diagnostic-form drift:** if correct components still read like a progress form or workflow tool, rename/soften labels, reduce form-like prompt density, keep one paper surface as the page anchor, and rebuild p5/p6/p7 against workbook/planner/handbook canon anchors.
- **Rendered text glitch:** inspect the page PNG and repair ambiguous glyphs or punctuation with safer wording, spacing, or fonts.
- **Answer leakage:** remove key pages from student output and scan generated PDF text.
