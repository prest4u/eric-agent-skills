| token | hex | 来源 |

没有 `primary` / `brand` / `band-h` / `punch-gutter` / `frame-inset`。不要加浅青、砂褐、新闻粗米、近白。

纸色口头叫砖红 `#D08A72`，**不是** F 砂褐 `#C4A882`，**不是** 家长说明册 `#EFE4D0`，**不是** I 新闻粗米 `#D2CBB8`，**不是** D `#DDE8E4`，**不是**近白。

色相必须偏红：R 明显高于 G，G 不得抬到砂黄。禁止用 `#C4A882` 或任何黄褐砂纸冒充砖红。

## 页边距、票根与纸张

A4 竖。`margin: (top: 18mm, bottom: 28mm, left: 16mm, right: 16mm)`。底边 28mm 是为了给 22mm 票根留出内容区。

票根几何锁死：

- 整页是一张票。底 **22mm** 为票根带（`stub-h = 22mm`）
- 正文与票根之间：一排小圆孔齿孔撕线（`perf-count = 44`，直径 1.44mm，左右各留 8mm）
- 票根只印：「青云」+ 案例号 + 页码 `01`，以及「非正式官方文件 · 不保证录取」
- 页脚只住在票根里。`header: none`，`footer: none`
- 封面与内页都画同一 overlay，由 `ticket-chrome()` 画在 `page.background`

禁止：左 12mm 竖列打孔、顶 9mm 填色带、通栏黑底报头、四周 6mm 细框、六栏。

## 正好 4 条硬差

1. **离开 J 活页齿孔（不要复用）。** J 石灰 `#C9C6BF`，左 `punch-gutter = 12mm` 竖虚线 + 7 个 2.9mm 圆孔，行楷题+黑体文。本皮砖红 `#D08A72`，齿孔是底边横向撕线，黑体题+行楷文，无左孔。
2. **离开 I 新闻栏（不要复用）。** I 纸 `#D2CBB8`，`columns-n = 6`，封面通栏黑底反白标题。本皮无六栏、无报头、无顶带；品牌在底票根。
3. **离开 D 识别册 9mm 顶带（不要复用）。** `band-h = 9mm`，纸 `#DDE8E4`，品牌 `#2F4A47`。本皮无 `band-h`，纸必须读红，青云印在底 22mm 票根。
4. **离开 F 朱印砂卷（不要复用）。** F 砂褐 `#C4A882`，四周 `frame-inset = 6mm` 连续细框，封面框内朱印「青云」。本皮无框、无印；`#D08A72` 不是 `#C4A882`。
