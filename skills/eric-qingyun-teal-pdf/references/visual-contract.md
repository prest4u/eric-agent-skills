# 青云识别册 · 视觉合同

本底盘是新造的「青云识别册」，不是旧 D 换色，也不是 A 雾蓝白换青色。旧 D（近白纸 + 方块 + 细轨 + 宋体）已废止。

## 气质

浅青灰卡 + 顶通栏反白「青云」+ 全无衬线。纸本身带色，识别靠通栏，不靠方块、不靠左「青」柱、不靠右页签。

## 四条硬差异（已建成，禁止改）

1. **纸**：浅青灰卡 `#DDE8E4`。不是近白纸 `#F4F6F5` / `#F5F6F4`，也不是纯白。
2. **字**：全无衬线。中文 PingFang SC / Hiragino Sans GB；拉丁若需要用 Avenir Next / Helvetica Neue。禁止宋体 / STSong / 衬线标题。
3. **网格**：出血顶通栏 **9mm**，填品牌色，无左轨、无左「青」字柱、无右切口页签。表 `stroke (x: none, y: hair)`，只有行底线，无竖线、无满框网格。
4. **封面**：顶带反白「青云」+ 大号无衬线标题「选科指导报告」+ 学生行 + 一句前提。禁止 DOCUMENT / STATUS 底栏对，禁止浅青方块，禁止左「青」纪念柱。

## 封面 / 页眉语法

- **顶通栏**（封面与内页同一套）：9mm 品牌底，反白字。左「青云」，中「选科指导 · 化名 · 省」，右案例号。
- **封面标题**：苹方 30pt medium「选科指导报告」。其下学生行 12pt 说明色，再下一句前提。
- **封面底**：一根发丝线 + 微字版本/日期/合成示例。没有 DOCUMENT / STATUS，没有双色 split-rule。
- **内页页眉**（第 2 页起）：同一根顶通栏，不是第二套系统。
- **页脚**：`青云` · `非正式官方文件 · 不保证录取` · 页码 `01`。封面无页脚。禁止印「视觉方案 D」。

## 内页语法

- `section-head`：无衬线标题 + 可选前提。没有编号细轨，没有竖线。
- `read-trio`：三栏「事实 / 判断 / 待核验」，栏底一根发丝。不是勾选网格。
- `row-table` / `gate-table`：只有行底线，无竖线，无单元格填色，不上交通灯。只谈门是否关上，**不开冲稳保**。
- 标签用中文（事实 / 判断 / 待核验），不用拉丁铬条。
- 禁止渐变、发光、厚薄荷网格、临床勾选框、医院绿通栏、浅青方块、左「青」柱、右页签。
