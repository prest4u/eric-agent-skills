# Student and Source Contract

Load this reference only when generating answerable exercises, paired student/teacher editions, or source-backed claims.

## Answerable practice and parity

Give each task a complete direction and every passage, sentence, option, datum, example, or taught mechanism needed to answer it. Tie it to the lesson target and observable signal.

Build the student edition first. Build the teacher edition from the same ordered task set:

| Surface | Include |
|---|---|
| Student | Natural directions, required inputs, response space, and student-safe success criteria. |
| Teacher | The complete student wording and inputs in the same order, plus the matching answer, explanation, likely observable error, repair move, and retry. |

Check task-level parity: no student task may be missing, duplicated, reordered, or silently rewritten in the teacher edition. Keep answers and teacher-only material out of the student edition, including expected responses, repair strategy, provenance ledgers, source IDs, build IDs, internal task/target labels, psychological labels, “trap”, “first-fail”, or “挖坑”.

Use anonymized learner context and omit names or scores when they are unnecessary. Describe observable work, not inferred traits.

## Source truthfulness

Before calling material `official`, `real exam`, `past paper`, `current`, or `latest`, directly verify a reliable source that supports the exact jurisdiction or exam, year, document, and question/page/section locator. Record the observed date when currency matters. A search snippet, filename, memory, or similar-looking question is not enough.

If the source is absent, incomplete, stale, or conflicting:

1. Withhold the claim and say what could not be verified.
2. Ask the user for a reliable source when exact sourced material is essential.
3. Otherwise create clearly labeled `original practice` and continue the lesson, exercise structure, skills work, and other source-independent parts.

For example, a request for the latest Tianjin Gaokao paper without a reliable source must not produce invented question numbers or provenance. Request the paper/link or continue with original practice aligned to the named skill without claiming it is a Tianjin real-exam item.

Use only authorized extracts and respect copyright. Do not reproduce an entire protected paper merely because a source can be found.
