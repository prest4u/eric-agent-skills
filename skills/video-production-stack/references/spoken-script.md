# Spoken-script Guidance

Read this reference only when drafting or polishing narration, voiceover, a presenter script, or captions derived from spoken prose.

## Preserve the source boundary

- Keep names, quotations, steps, dates, prices, data, claims, and examples grounded in the supplied script or verified evidence.
- Do not invent first-person experience, customer stories, results, or certainty to make the voice sound human.
- Preserve the author's argument when the request is only to make the language speakable. Explain before making a structural rewrite.
- Mark uncertain facts as `[verify]` and unsupported production directions as `[visual to confirm]` instead of guessing.
- Remove or generalize private names, accounts, messages, student/client material, and contact details unless their use is explicitly authorized.

## Three passes

1. **Meaning and recording reality** — check the hook, argument order, demonstrations, visual cues, factual locks, and target duration. Make sure every screen action has a real corresponding shot or mark it unresolved.
2. **Speech rhythm** — prefer short clauses, one action or judgment per sentence, natural pauses, and conclusion-before-explanation. Remove bureaucratic transitions and ornamental filler without flattening the author's voice.
3. **Recording marks** — add only useful cues such as `[pause]`, `[screen]`, `[close-up]`, or `[caption]`. Do not bury the script in stage directions.

For Chinese narration, use sentence length as a readability signal rather than a rigid quota. Break tongue-twisting chains, consecutive abstractions, and comma-heavy sentences. Use colloquial connectors sparingly; do not paste in fashionable catchphrases.

## Output

Return the revised script, a short recording note with estimated duration and needed visuals, and a concise list of material changes or unresolved facts. For a long script, polish a representative opening section first only when a style decision remains genuinely uncertain; otherwise complete the requested scope.

Read the text aloud or simulate an aloud read before delivery. The script passes when it can be spoken without obvious stumbles, retains the source meaning, and introduces no unsupported facts or experiences.
