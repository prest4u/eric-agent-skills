# 视觉合同 · 青云家长说明册

锁死对象：Document Master 淘汰 B 苔绿象牙之后的替代底盘。不是 A 的换色，禁止复用栏轨几何。

禁止发明第二套品牌色。禁止把 A/B/C/D/E 的栏轨、结构色或纸色搬进来。不要声明 `primary`。

## 四硬差（主差正好四条）

1. **纸**：本皮暖黄书纸 `#EFE4D0`。A 近白 `#F4F5F3`。B（已淘汰）暖象牙 `#F6F3EA`。C 近白 `#F3F3F1`。E 冷灰书纸 `#E6E4DE`。纸必须离开 A/B/C/E。
2. **字**：本皮楷题 + 仿宋正文。A 苹方/咨询 sans + `01` 栏轨编号。B 苔绿栏轨字 + 仿宋 pull quote。C 密排宋/sans 微字。E 宋体章节号（一 / 二）。
3. **网格**：本皮左 **38mm 边注** / 沟 6.5mm / 右正文，真双栏。A/B 都是 16mm `rail-head` + `split-rule`。C 无栏轨但密页无边注列。E 大页边、宋体章节，无 38mm 边注。
4. **封面**：本皮竖向纸签只写「青云」+ 居中大楷题辞；无页眉页脚，无拉丁底栏。A 拉丁 kicker + DOCUMENT 底栏。B 咨询封面 + 苔绿双轨。C 拉丁 eyebrow（如 QINGYUN OPINION）。D 浅青方块识别。E 居中机构名 + 方案微标。

## 纸色与墨

| token | hex | 角色 |
|---|---|---|
| `paper` | `#EFE4D0` | 暖黄书纸 |
| `ink` | `#3A3228` | 暖墨。不要把 E 的冷灰 `#262626` 直接搬来 |
| `muted` | `#6E6356` | 边注、次级 |
| `micro` | `#8A7F70` | 页脚、题记 |
| `hair` | `#C9B89A` | 暖黄纸上的发丝线 |

没有 `primary` / `secondary`。不要加雾蓝 `#5D6C75`、苔绿 `#626A56`、浅青结构色。

## 字体栈

| 角色 | 栈 |
|---|---|
| 标题 / 题辞 / 题签 / 边注标签 / 页脚微字 | `Kaiti SC`, `STKaiti`, `Kaiti TC` |
| 正文 / 门表单元格 | `STFangsong`, `Songti SC`, `STSong` |
| 拉丁 / Avenir / 苹方正文 | **不用** |

本机有 `Kaiti SC`、`STFangsong`。缺字时先对 Typst 名，不要用苹方交差。

正文字号 10.5pt，边注 8.5pt，`lang: "zh"`。正文两端对齐，首行缩进 2em。边注不缩进、不平齐强行两端。

## 页边距与纸张

A4 竖。`margin: (top: 22mm, bottom: 20mm, left: 15mm, right: 17mm)`。

边注列从左边距起算，固定 `sidenote-width = 38mm`，`sidenote-gutter = 6.5mm`，正文吃剩余。页码放左边注底部或页脚左栏，用普通数字，不要 `01`。

封面用单独 `page`，无页眉页脚。

## 封面

- 题签：竖向纸签，细框或细线匣，只写「青云」楷体。偏右上方，像线装书封面题签。
- 题辞：居中大楷书，例如「给家长的说明」或「选科说明」。
- 化名 · 省 · 高一选科 · 案例号，用楷体微字。
- 底句：「合成示例 · 非正式官方文件 · 不保证录取」。
- 禁止拉丁 kicker（QINGYUN / DOCUMENT / STATUS）。禁止封面底栏。

## 铬条策略

允许：

- 题签细框 / 细线匣
- 门表只有横向 hairline：`stroke: (x: none, y: 0.4pt + hair)`
- 边注与正文以空间分栏，不用竖向色轨

禁止：

- A/B 的 16mm 左栏轨与 `rail-head`
- A/B 的 `split-rule`
- D 页眉浅青方块
- 拉丁 eyebrow
- 填色卡片、可勾选框、红黄绿、冲稳保上色
- 封面 DOCUMENT / STATUS 底栏

API 必须提供：`parent-doc`、`cover-page`、`spread(note, body)`、`gate-table`；`labeled-rows` 可选。不要出现函数名 `rail-head` / `split-rule`。

## 页眉页脚

封面：无页眉页脚。

第 2 页起：无栏轨页眉。页脚左边注列写「家长说明册」+ 页码，主栏写「青云 · 非正式官方文件 · 不保证录取」。原文必须出现，可拆到边注 + 主栏。

## 禁词

客户可见只写「青云未来」。禁止：青云知路、青云志愿。

禁止：上岸率、录取概率、保证上岸、一定录取、公章、国徽、真名。

## 不是什么文种

- 不是志愿冲稳保表、不是填报执行清单
- 不是可勾选核对表
- 不是确认书 / 签发单（偏 C）
- 不是雾蓝白咨询案卷（偏 A）
- 不是选科长文编辑纸本（偏 E）
- 不是三人经营讨论稿、不是渠道返佣合同
- 不是英语教材、不是讲座幻灯

本季只做家长说明册（售前 / 转介 / 家长讲解）。门表只谈门是否被关上，不上色，不开院校冲稳保。
