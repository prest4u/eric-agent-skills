# 视觉合同 · 青云活页齿孔

锁死对象：第二轮新底盘 J。不是 A 的换色，不是家长说明册换色。禁止复用栏轨几何、38mm 边注、竖题签、暖黄书纸。

禁止发明第二套品牌色。禁止把 A/B/C/D/E 或家长说明册的栏轨、边注、结构色或纸色搬进来。不要声明 `primary`。

## 四硬差（主差正好四条）

1. **纸**：本皮石灰 `#C9C6BF`。A 近白 `#F4F5F3`。家长说明册暖黄书纸 `#EFE4D0`。B（已淘汰）暖象牙 `#F6F3EA`。C 近白 `#F3F3F1`。E 冷灰书纸 `#E6E4DE`。纸必须离开 A 和家长说明册。
2. **字**：本皮行楷题 + 黑体文。A 苹方/咨询 sans + `01` 栏轨编号。家长说明册楷题 + 仿宋正文 + 竖题签。不要把苹方当正文主栈。
3. **网格**：本皮左 **12mm 齿孔**（竖虚线 + 一列圆点），正文从齿孔右侧通栏。A 是 16mm `rail-head` + `split-rule`。家长说明册是 38mm 边注 / 沟 6.5mm / 右正文。禁止 `rail-head`。
4. **封面**：本皮像从活页夹抽出的一页：左边同样齿孔，右上横排小「青云」，主标题左齐行楷，无咨询页眉，无拉丁底栏。A 拉丁 kicker + DOCUMENT 底栏。家长说明册竖向纸签 + 居中大楷题辞。

## 纸色与墨

| token | hex | 角色 |
|---|---|---|
| `paper` | `#C9C6BF` | 石灰纸。冷石灰，不是暖黄 |
| `ink` | `#2C2C2A` | 冷墨。石灰纸上要够对比 |
| `muted` | `#5C5B57` | 次级、右上小「青云」、meta |
| `micro` | `#7A7974` | 页脚、题记 |
| `hair` | `#A8A59E` | 门表发丝线 |
| `punch` | `#6A6964` | 齿孔虚线、圆点 |

没有 `primary` / `secondary`。不要加雾蓝 `#5D6C75`、苔绿 `#626A56`、浅青结构色、暖黄 `#EFE4D0`。

## 字体栈

| 角色 | 栈 |
|---|---|
| 标题 / 封面主标题 / 节标题 / 门表列表头 / 行标签 | `Xingkai SC`, `Xingkai TC` |
| 正文 / 门表单元格 / 页脚 / 右上小「青云」 | `Heiti SC`, `STHeiti`, `Hiragino Sans GB` |
| 楷 / 仿 / 苹方正文 / 拉丁 kicker | **不用** |

本机有 `Xingkai SC`（Light/Bold）、`Heiti SC`（Light/Medium）、`STHeiti`。缺字时先对 Typst 名，不要退回苹方或楷仿。

正文字号 10pt，页脚 7.5pt，`lang: "zh"`。正文两端对齐，首行不缩进（工作活页，不是书册）。

## 页边距、齿孔与纸张

A4 竖。`margin: (top: 20mm, bottom: 18mm, left: 19mm, right: 17mm)`。

齿孔几何锁死：

- 中心距左裁口 `punch-gutter = 12mm`
- 竖虚线：`stroke: (paint: punch, thickness: 0.45pt, dash: (1.1pt, 1.6pt))`，顶到底
- 圆点：7 个，沿虚线等距，空心圆，直径 2.9mm
- 左页边距 19mm，让正文避开孔；不要做成 16mm 色条栏轨

页码用普通数字，不要 `01`。封面与内页都画同一 overlay，由 `binder-holes()` 画在 `page.background`。

## 封面

- 像从活页夹抽出的一页，不是题辞海报
- 左边同样 12mm 齿孔（虚线 + 圆点）
- 右上横排小「青云」（黑体，不是竖题签）
- 主标题左齐行楷大字，例如「选科说明」
- 下方左齐黑体 meta：化名 · 省 · 高一选科 · 案例号
- 底部左齐：「合成示例 · 非正式官方文件 · 不保证录取」
- 禁止拉丁 kicker（QINGYUN / DOCUMENT / STATUS）。禁止封面底栏。禁止咨询页眉。禁止居中题辞。禁止竖题签匣。

## 铬条策略

允许：

- 左 12mm 齿孔：虚线 + 空心圆点
- 门表只有横向 hairline：`stroke: (x: none, y: 0.4pt + hair)`

禁止：

- A/B 的 16mm 左栏轨与 `rail-head`
- A/B 的 `split-rule`
- 家长说明册 38mm 边注、`spread`、竖题签 `title-slip`
- D 页眉浅青方块
- 拉丁 eyebrow
- 填色卡片、可勾选框、红黄绿、冲稳保上色
- 封面 DOCUMENT / STATUS 底栏
- 断轨

API 必须提供：`binder-doc`、`cover-page`、`gate-table`、`binder-holes`；`punch-gutter` 为 12mm 几何常量；`labeled-rows` 可选。不要出现函数名 `rail-head` / `split-rule` / `parent-doc` / `title-slip` / `sidenote-width`。

## 页眉页脚

封面：无页眉页脚。右上小「青云」写在版心，不是咨询页眉。

第 2 页起：无栏轨页眉。页脚左写「青云 · 活页齿孔」+ 页码，右写「非正式官方文件 · 不保证录取」。原文必须出现。

## 禁词

客户可见只写「青云未来」。禁止：青云知路、青云志愿。

禁止：上岸率、录取概率、保证上岸、一定录取、公章、国徽、真名。

不要在客户页写「客户可见只写青云未来」这种内部句。

## 不是什么文种

- 不是志愿冲稳保表、不是填报执行清单
- 不是可勾选核对表
- 不是确认书 / 签发单（偏 C）
- 不是雾蓝白咨询案卷（偏 A）
- 不是家长说明册（暖黄 + 38mm 边注 + 题签）
- 不是选科长文编辑纸本（偏 E）
- 不是三人经营讨论稿、不是渠道返佣合同
- 不是英语教材、不是讲座幻灯

本季只做活页抽出页气质的选科说明。门表只谈门是否被关上，不上色，不开院校冲稳保。
