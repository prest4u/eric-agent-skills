# Eric Review Quick Start

- Use `QUICK_REVIEW` for a concise verdict and important findings.
- Use `REVIEW_AND_FIX` when Eric asks for both critique and a repaired deliverable.
- Use `FORMAL_SIGNOFF` only for explicit approval or high-impact delivery.
- Review the actual artifact. If it does not exist, build or request it first.
- Ordinary review needs no matrix, packet, seven-section report, or independent reviewer.
- Formal sign-off freezes identity, checks mandatory evidence, and uses one independent reviewer.
