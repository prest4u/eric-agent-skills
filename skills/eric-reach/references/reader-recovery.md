# Recover an existing reader

Use for an exact failed read or authorized maintenance, not background polling.
Preserve the failed target and account-safety stop conditions. Do not change
network/security settings, export cookies, or install another bridge as a retry.

## Find the failing layer

1. **Execution permission:** sandbox localhost `EPERM` proves only that the
   process could not connect. A helper may collapse it into `stopped`. Use the
   host's approval route for one read-only status probe; do not weaken settings.
   Host-side `ECONNREFUSED` is distinct evidence of an absent local listener.
2. **Bridge:** inspect the existing extension through supported Chrome UI.
   Within authorized maintenance, the installed health check may restart an
   existing daemon without new permissions. Do not automatically install/enable
   an extension, select an ambiguous profile or grant new access.
3. **Session:** bridge-ready does not mean logged in. Test only the authorized
   target/query. A login wall needs the user's ordinary login or an explicitly
   authorized existing session. Never extract/import credentials.
4. **Adapter:** inspect actual help and source. An output limit can apply after
   pagination. Check retries, credential handling and playback before execution.
5. **Platform/content:** distinguish login, verification, denial, rate limits,
   empty extraction and genuinely missing captions. None alone proves the
   platform is permanently unsupported.

Record time, versions, route, exact target and whether the request reached the
platform. Keep secrets, account/profile identifiers and temporary note locators
out of durable reports. A tool timeout may have partially run; preserve the last
confirmed state and do not launch a retry loop or claim completion.

## Doctor is not a platform verdict

The inspected local Agent Reach 1.5.0 Twitter checker returns a warning even
with OpenCLI connected because it does not execute a platform read. Its
`active_backend` can remain empty. Do not require that field before an otherwise
permitted public normal-page read or one bounded query through a ready existing
bridge. Do not patch doctor to mark untested platforms successful.

OpenCLI `doctor` auto-starts its daemon and runs a bridge probe; it is not a
passive process-list command. Review installed behavior and use it only within
the authorized existing setup. A whole-platform Agent Reach doctor is not
necessary merely to diagnose one reader.

## Specific routes

- **X:** public Chrome post text can work while login-backed interaction/search
  is unavailable. Record original text and actually visible parent/quote facts;
  keep missing nodes explicit. Inspected OpenCLI 1.8.7 `twitter search` and
  `twitter thread` both read cookies into Node; neither is permitted under the
  current no-export contract. Search with limit 5 sends count 15 on its first
  request and may paginate; thread can paginate five times before trimming.
  A small output limit does not prove bounded acquisition. Do not substitute
  search for thread. No compliant CLI discovery route is verified here; report
  the missing source link if no permitted discovery reader is available, without
  new login, credential export or a backend switch to obtain it.
- **Xiaohongshu:** search once with at most five results; read one selected note
  only if available. `AUTH_REQUIRED` from a login wall is a session blocker.
  Stop for the user's normal login; do not start QR automation, import cookies,
  switch backend to evade it or repeat the same unchanged query.
- **YouTube:** distinguish playability, captions, speech and visual evidence.
  The inspected OpenCLI 1.8.7 transcript adapter calls `playVideo()`; a temporary
  mute must be verified before playback. A supported normal-page transcript
  reader can be evaluated separately under the same silence/access rules.
  Do not download media as an unrequested fallback. A reader's existence does
  not prove it returned nonempty captions.

## Upstream and prior success

Use the exact repository in [source and update](source-and-update.md). Preserve
custom rules and backups, validate/freeze a candidate before cutover, and never
run `agent-reach skill --install` over Eric's overlay.

The local 2026-09-27 maintenance record rejected an OpenCLI 1.8.8 candidate for
retry/credential/confirmation issues and retained 1.8.7. Review whether those
findings are resolved before replacing it; an upgrade advertisement is not a fix.

Use relevant normal maintenance/acquisition artifacts for past success. Doctor
`ok`, dependencies, a tab title or local ASR smoke is not proof that a platform
transcript was obtained. Do not inspect secret stores, restricted conversations
or unrelated history. Bridge-ready, original-readable, interactions-readable and
nonempty-transcript-read are separate outcomes. Leave precise user steps and
independent retest targets; do not schedule them.
