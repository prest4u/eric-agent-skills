# Evidence-driven repair

Preserve the failing command or observation and the affected artifact state. Make one targeted repair and repeat the relevant check.

If the same failure repeats without new information, gather diagnostic evidence and change the hypothesis or method. Continue useful authorized work when the evidence supports progress; return a concrete blocker only when a real dependency prevents it. Rephrasing the same guess does not create new evidence.

Use normal command output, screenshots, or concise notes. No JSON fingerprints, counter ledger, or routine repair approval is required. Ask again only when the next action changes scope, cost, irreversibility, or authority.

For a stalled required independent review, allow one replacement for the same question. If it also cannot conclude, deliver the local candidate and pending review while keeping dependent release/high-impact actions blocked. Resume only when evidence, the material candidate, or review capability changes.

The loop ends on sufficient acceptance evidence or an explicit unresolved dependency. Optional polish and an evaluator's new preferences do not create further required rounds.
