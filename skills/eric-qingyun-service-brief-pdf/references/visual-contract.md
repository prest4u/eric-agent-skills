# 视觉合同（Slate White 独立版）

本文件已收录运行本 Skill 所需的色彩、字体、版式和页角色规则，无需安装或读取 `$eric-slate-white-pdf`。若该 Skill 已安装，可只读对照，但不是依赖。

## 沿用（禁止改）

| 项 | 值 |
|---|---|
| 纸 | `#F4F5F3` |
| 墨 | `#24282A` |
| 结构 | `#5D6C75` |
| 次级 | `#7D8990` |
| 说明 / 微字 | `#747B7E` / `#626B6F` |
| 线 | `#CCD2D3` |
| 纸张 | A4 竖 |
| 边距 | 上 24mm、下 22mm、左右 25mm |
| 栏轨 | 16mm + 10mm gutter |
| 字体 | 宋体标题与正文；苹方导语/表/指示；仿宋仅少量表外引句；Avenir/数字 |

不要引入苔绿、陶土、教材青绿/品红、纯 `#FFFFFF`、第二套品牌色。

## 本系统增量

- **身份页眉**（第 2 页起）：案例号 · 化名 · 省年批次 · 版本 · 日期 · 仅供本家庭
- **案卷页脚**：机构署名青云未来 · 非正式官方文件 · 不保证录取 · 以签发版为准 · 页码。封面无页眉页脚。
- **判断类型标记** `judgment-mark`：冲=细线常规字、稳=中线、保=重线。不上红黄绿。
- **免责四句** 固定原文，见 `assets/theme.typ`。
- **事实 / 判断 / 待核验** 用 `evidence-row` 标签 `FACT` / `JUDGEMENT` / `UNVERIFIED`，不用 badge。
- 封面机构署名：`青云未来`。不要印知路或竞品「青云志愿」。
- 封面标题 28–34pt，不要教材封面 38pt 口号。

## 页角色怎么用

按下列页角色依文种取用：

| 角色 | 志愿文书里做什么 |
|---|---|
| Cover | 文种、案例、版本、签发状态 |
| Section opener | 怎么读 / 策略假设 |
| Evidence / judgement | 档案摘要、来源、待核验 |
| Argument / contrast | 两组对照，不写成好坏 |
| Numbered process | 服务步骤、五道检查 |
| Conclusion | 下一步、修改窗口 |
| Sources / notes | 来源年份与免责 |

密表（候选池、填报序号）单独成页，用 hairline，不要卡片墙。说明页保持约三分之一留白；清单页可以更满，宁可加页。

## 明确少做什么

Slate White 编辑性文档里偶尔可见的居中长引、文学停顿页，在 D3/D5/D6 **不要用**。D4 最多一处。不要每页左轨。不要填色卡片。
