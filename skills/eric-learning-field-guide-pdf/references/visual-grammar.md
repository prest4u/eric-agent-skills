# Learning field-guide visual grammar

## Colour system

Choose one low-to-medium saturation primary, one secondary, and one signal colour. Derive pale washes from those colours rather than adding unrelated hues. Keep body text near-black and rules dark enough for ordinary office printing. Recommended E01 family: forest green for observation and continuity, book-cloth blue for editorial navigation, and terracotta for decisions or reflection.

Use labels, numbers, line styles, position, and wording alongside colour. Check grayscale output to confirm the sequence remains readable without colour.

## Page-role rhythm

1. **Cover:** one documentary material field, a heavy title, quiet metadata, and a restrained bottom-right `Eric Teaching Studio` mark.
2. **Observation:** one proposition plus a bounded field task with time, scene, evidence, decision, and output.
3. **Trace:** a real image annotated with live HTML labels; pair it with a worked example and a learner move.
4. **Method:** combine a tactile insert with a short sequence and an explicit human/AI/boundary record.
5. **Practice:** continue the method through a visible path and a transfer check; avoid generic process diagrams.
6. **Close:** name the reusable output, add reflection prompts, state boundaries, and finish with one memorable practice principle.

## Image grammar

Prefer adult hands using blank paper, clothbound notes, rulers, clips, cards, workshop tables, or physical pathways. Use realistic light and materials. Keep faces and identity unnecessary unless the learning situation truly requires them. Generated or transformed images must contain no readable text, fake handwriting, logos, watermarks, UI, answer marks, or teaching content.

Use a different image on every image-bearing page. Record source/generation, prompt or deterministic transform, role, dimensions, text policy, and unique use.

## Print and typography

Use a firm modern CJK sans for Chinese headings and a condensed sans only for short Latin metadata. Keep body copy at a comfortable print size; treat 8.5 pt as a hard lower boundary, not a target. Use real A4 page boxes, page breaks, print-colour adjustment, and fixed overflow control. Inspect rendered PDF pages, not only the browser source.

## Reject patterns

Reject landing-page covers, dashboard panels, UI number blocks, repeated sparse forms, decorative colour bands, colour-only meaning, page-sized raster text, fake text in imagery, accidental title wrapping, weak body contrast, reused images, and same-agent final approval.
