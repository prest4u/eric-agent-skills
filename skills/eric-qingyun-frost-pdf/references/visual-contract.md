# 青云 · 霜蓝通缘 · 视觉合同

本底盘是新造的「霜蓝通缘」，不是识别册换色，也不是 A 雾蓝白换蓝色。识别册（浅青卡 + 9mm 顶通栏 + 全无衬线）是另一张皮，禁止混用。

## 气质

霜蓝卡 + 右缘 28mm 涂布色条 + 魏碑标题 / 黑体正文。纸本身带蓝，识别靠右缘竖排「青云」，不靠顶通栏、不靠方块、不靠左「青」柱。

## 四条硬差异（已建成，禁止改）

相对识别册 D（`$eric-qingyun-teal-pdf`：纸 `#DDE8E4` + 顶通栏 9mm + 全无衬线苹方）：

1. **纸**：霜蓝 `#C5D4E0`（约 RGB 197, 212, 224）。这是蓝，不是识别册浅青卡 `#DDE8E4`，也不是近白 `#F4F6F5`。若目检发绿 / 发青，即失败。
2. **字**：标题 **Weibei SC**（魏碑）；正文 **Heiti SC** / STHeiti（黑体）。不是识别册全无衬线 PingFang。拉丁仅案例号需要时回退 Avenir Next / Helvetica Neue。魏碑按字面供墨，不另加 bold。
3. **网格**：右缘 **28mm** 通高涂布色条（`#2B4C63` 霜石蓝），竖排页码写在条内。无顶通栏，无左轨，无左「青」柱，无 DOCUMENT/STATUS 底栏。
4. **封面**：右条通高，条内竖排白字「青云」。主区左对齐魏碑大标题「选科指导报告」，其下学生行，再下一句前提。禁止识别册那种顶通栏反白品牌。

## 封面 / 页眉语法

- **右缘色条**（封面与内页同一套几何）：28mm 霜石蓝，通高。封面条内竖排较大「青云」；内页条内顶部小「青云」。页码 `01`–`04` 竖排（旋转）写在条底，不进页脚。
- **封面标题**：魏碑 40pt 左对齐「选科指导报告」。其下黑体 12pt 学生行，再下一句前提。
- **封面底**：一根冷蓝灰发丝 + 微字版本/日期/合成示例。没有 DOCUMENT / STATUS，没有双色 split-rule。
- **内页**：无顶通栏。主区在色条左侧，左对齐。魏碑章节题。
- **页脚**：无。禁止印内部底盘名。客户可见只写「青云未来」。

## 内页语法

- `section-head`：魏碑标题 + 可选前提。没有编号细轨，没有竖线，没有顶带。
- `read-trio`：三栏「事实 / 判断 / 待核验」，栏底一根发丝。不是勾选网格。
- `row-table` / `gate-table`：只有行底线，无竖线，无单元格填色，不上交通灯。只谈门是否关上，**不开冲稳保**。
- 标签用中文（事实 / 判断 / 待核验），不用拉丁铬条。
- 禁止渐变、发光、厚薄荷网格、临床勾选框、医院绿通栏、浅青方块、左「青」柱、右页签、顶通栏。
