# Transaction Dealbook Production Grammar

## Page roles

Use distinct editorial structures rather than repeating a dashboard shell:

1. Cover — state the transaction thesis and establish the packet/material metaphor.
2. Belief or mandate — pair a short thesis with audience and intended outcome.
3. Diligence — convert assertions into numbered, falsifiable questions with evidence entrances and an unresolved register.
4. Dependency assembly — show the conditions that must be complete before a pilot, signing step, or integration move.
5. Integration decision — use explicit HOLD / PILOT / TRANSFER or equivalent gates tied to evidence packets.
6. Post-close handoff — name business, decision, data, operating, and delivery owners; end with the human-responsibility boundary.

## Visual system

- Primary: charcoal `#171719` for text, dark fields, and structural rules.
- Secondary: silver grey `#C4C5C6` with pale neutral `#F0F0EF` for evidence fields.
- Signal: oxblood `#6F1D2C`, darkened to `#541421` on light fields or lightened to `#D9A8B2` on charcoal fields.
- Use the signal only for risk, unresolved evidence, decision gates, and responsibility markers.
- Pair every signal with words, numbering, placement, or rule weight so grayscale printing remains intelligible.
- Prefer serif display type for theses and compact sans/condensed sans for evidence labels. Keep body text dark and comfortably above 8.5 pt.

## Image and evidence policy

Use restrained, material-true scenes such as layered packets, divider tabs, diligence files, and integration assemblies. Each image must have a unique page role and file. Record asset id, path, source/generation, prompt or deterministic transform, dimensions, text policy, page role, and unique use. Reject logos, fake finance symbols, visible text, watermarks, and decorative imagery unrelated to the evidence structure.

## Verification

Require a fresh PDF-origin render of every page after the final PDF. Check searchable text page by page; A4 dimensions; zero JavaScript or automatic actions; no blank pages; no external requests; no overlap, occlusion, masking, clipping, or overflow; unique images; and source/PDF/render/contact-sheet freshness. Freeze exact SHA-256 hashes before independent review.
