# Editorial Judgment for Parent Feedback

Read this reference before drafting, revising, or auditing parent-facing feedback.

## Outcome Priority

Make decisions in this order:

1. Give an accurate picture of what the student can do now, where the main difficulty is, and how serious it is.
2. Keep the relationship calm, respectful, and constructive.
3. Let teacher professionalism show through precise judgment rather than through long knowledge lists or diagnostic jargon.

Do not trade accuracy for warmth, and do not display expertise by multiplying problems.

## Source Authority

Use today's evidence in this order:

1. Eric's explicit description of today's classroom performance.
2. The student's actual first attempt, answers, writing, score, or submitted homework from today.
3. A dated observation record from the same lesson.
4. Earlier feedback, only to describe a verified change over time.
5. The lesson plan or handout, only to establish what was taught.

A lesson plan proves what the teacher intended or completed. It never proves that the student understood or mastered it. Earlier feedback never becomes today's result without fresh classroom evidence.

## Private Decision Card

Before writing visible prose, silently settle these fields:

- `course_mode`: one-to-one, class/group, or trial
- `overall_mastery`: the most accurate overall conclusion supported today
- `observable_basis`: one or two classroom events that justify that conclusion
- `primary_issue`: the one issue that most changes what the parent needs to understand for this feedback unit
- `severity`: stable, minor slip, understood-not-independent, or primary difficulty
- `response_to_support`: independent, self-corrected after a reminder, completed with support, or not yet completed
- `secondary_observations`: useful but lower-priority facts
- `homework_status`: assigned work and any verified completion issue

`observable_basis` is an internal decision term. Do not write “证据显示” or repeatedly use “证据” in the parent message.

Keep dimensions separate:

- “上课认真” supports a conclusion about participation, not mastery.
- “提醒后能自行改正” supports understanding with incomplete independence.
- “第一次独立完成且大部分正确” supports stable mastery.
- “作业按时提交” supports work habits, not automatic understanding.

If `overall_mastery`, `primary_issue`, or `severity` cannot be determined after checking available files, ask one decisive question such as:

> 今天这部分是能够独立完成，还是提醒后才能完成？

Do not send a questionnaire. Do not infer the answer from teaching materials. If Eric confirms that no meaningful problem appeared, do not manufacture one.

## Severity Ladder

Use this ladder internally to control prominence and wording. Never print the level names.

| Internal level | Evidence threshold | Parent-facing direction |
|---|---|---|
| Stable | Can complete independently with consistent accuracy | `能够独立完成` / `掌握比较稳定` |
| Minor slip | Core understanding is present; an occasional error is self-corrected after a reminder | `基本掌握` / `提醒后能够自行修正，整体影响不大` |
| Understood, not independent | Can follow or repair with support but is not yet stable alone | `已经能够理解，但独立完成时还不够稳定` |
| Primary difficulty | Repeatedly blocks completion or meaning and materially affects current performance | `目前主要困难在……，需要集中练习` |

Never promote or demote a level for rhetorical balance. Avoid `基础很差`, `问题严重`, `必须马上`, or `切实下功夫` unless Eric explicitly supplies an equally strong verified judgment and asks to preserve it.

## Prominence Rules

- Give each feedback unit one main conclusion, not a catalog of observations. The unit is the single student in one-to-one or trial feedback; in class feedback, it is the shared class conclusion or one named student's line.
- Mention at most one primary issue per unit. Distinct verified difficulties for different students in the same class may all appear. A minor issue belongs only when it changes the parent's understanding or the student's action.
- Put the strongest supported conclusion first. Do not bury stable performance under a small error.
- State whether the student worked independently or needed a reminder when that distinction is known.
- Do not force a weakness into every lesson. A genuinely strong lesson may report stable performance and move directly to homework.
- Keep behavior, mastery, and homework separate. Attention or missing work becomes the headline only when it is genuinely the central issue.

Cold-read `②课上反馈` before finalizing. A parent should be able to tell:

1. 会不会；
2. 卡在哪里；
3. 严不严重；
4. 是独立完成，还是提醒后能改。

## Mode Rules

### One-to-one

- Default to two short paragraphs in `②课上反馈`.
- Paragraph one: overall mastery plus one or two observable classroom results.
- Paragraph two: the single primary issue and its calibrated severity, only when one exists.
- Do not repeat the knowledge list from `①课上内容`.

### Class or group

- State shared content and shared mastery once.
- Give each named student one or two sentences, but include only real individual differences: participation, a specific learning result, response to a reminder, or homework status.
- Apply the primary-issue budget separately to the shared class conclusion and to each named student. Do not suppress one student's verified difficulty because another student has a different one.
- Do not repeat `表现不错` for every student or invent differences to fill lines.
- If no individual information exists, ask once whether anyone needs separate mention. If not, keep individual lines factual and do not invent mastery claims.
- Put shared assignments in `③课后作业`. Mention missing or partial work under an individual student only when verified, using neutral wording such as `目前提交了一部分，剩余内容需补齐`.

### Trial

- Show diagnostic value through prioritization, not through a long problem list.
- Give the main learning need roughly 60–70% of the diagnostic space.
- Keep no more than two secondary observations, together using no more than 30–40% of the space and clearly lighter wording.
- Separate `目前最需要关注的一项` from facts that were merely noticed.
- Do not turn the ending into a sales pitch, a course preview, or a high-pressure verdict.

## Information Budget

- `①课上内容`: two to four concrete items; stop after the list. Do not add an empty summary of why everything matters.
- `②课上反馈`: use the mode rules above. Prefer a compact, decisive read over a comprehensive report.
- `③课后作业`: use numbered, executable tasks when work is assigned. If none is assigned, write one factual sentence such as `本次课无额外作业。` Do not invent work, add motivational closure, or preview the next lesson.
