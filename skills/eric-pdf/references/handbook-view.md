# Eric PDF Handbook View Anchor

Use this original, text-only design grammar when creating scene vocabulary, lookup, review, expression, or memory handbooks that should feel premium but not decorative.

The public Skill intentionally redistributes no source-book screenshots. The rules below are an abstracted layout vocabulary, not a request to reproduce a particular book or page.

## Visual DNA

- Page: A4, warm ivory paper, wide margins, no background art.
- Typography: strong but restrained Chinese title, clear weight contrast, no negative letter spacing.
- Color: one clay action color, taupe metadata, warm hairlines, pale cream cards. Do not add extra accent colors unless the content truly needs semantic coding.
- Shape: small-radius cards and tables only. No nested cards, shadows, gradients, icons, badges, watermark, or sidebar decorations.
- Density: pages feel used but calm. Directory and plan pages can breathe; lookup pages can be dense if row height and line weight stay light.

## Page Patterns

Cover:

- Upper-middle title block, not a large poster hero.
- Title around 22pt, subtitle around 14pt, short clay rule, muted bottom meta.
- No header on cover. If the project wants printed page numbers on all pages, keep cover numbering quiet and centered.

Method and Directory:

- Three method cards in a single row for `先看场景 -> 再看功能 -> 最后词形`.
- Directory cards use two columns, short descriptions, and muted word counts.
- Let the directory occupy a page naturally; do not compress it into a table just to save space.

Lookup Tables:

- Use a pale header row and horizontal hairlines; avoid full spreadsheet grids.
- Keep word forms bold, but do not make every column visually loud.
- For long trigger/evidence text, truncate or split the table before row height becomes uneven.

Plan and Checklist Pages:

- Use repeated low-contrast cards with one clay label and one short action sentence.
- Avoid oversized headings inside cards; the page heading should be the dominant label.

## Guardrails

- Do not turn "premium" into more panels. Premium here means fewer colors, quieter hierarchy, and useful whitespace.
- Do not make supporting labels larger than the main section heading.
- Do not put source IDs, internal build labels, version words, or teacher-only terms in student-facing handbooks.
- If a new handbook starts looking heavy, return to this text grammar and remove the least functional visual layer first.
