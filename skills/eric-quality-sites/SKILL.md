# Eric Quality Sites

Use this as Eric's stable, memorable entry point for premium website work in any project.

## Authoritative workflow

1. Read `references/upstream/mengto-build-awwwards-quality-sites/SKILL.md` completely and use it as the primary visual-production baseline.
2. Read `references/upstream/vercel-web-design-guidelines/SKILL.md` when checking interface quality and `references/upstream/addy-frontend-ui-engineering/SKILL.md` when implementation craft or interaction behavior is central.
3. Select only the other installed Skills the task actually needs, such as visual-direction design, animation systems, GSAP/Lenis motion, frontend design, animation optimization, or frontend delivery.
4. Preserve the target project's framework, product semantics, data contracts, privacy boundaries, and repository instructions.
5. Inspect the real runtime at desktop and mobile widths. Verify interaction, reduced motion, accessibility basics, responsive behavior, performance health, and production build before handoff.
6. Treat supplied references as evidence for hierarchy, pacing, typography, composition, and motion quality—not as assets or layouts to copy.
