# 青云 · 选科指导报告（内部皮：军绿指索）

产品只写 **青云未来**。本 skill 是 wave-3 皮 M，**不是 H 霜蓝通缘换色，不是 F 朱印砂卷，不是 J 活页齿孔**。禁止复用 28mm 右通缘竖条、6mm 细框、朱印、左 12mm 齿孔。内部名「军绿指索」只出现在本文件与 `references/visual-contract.md`，**不得印上 PDF**。

先读本文件，再读 `references/visual-contract.md`，再 `#import "theme.typ"`。色值、字栈、拇指半圆只许按合同。

## 何时用 / 不用

**用：** 选科指导报告要做成军绿纸、全书隶书、右裁口四枚字典拇指索引。给要「翻到某门」手感、不要通高色条也不要细框印章的家长。本季文种是选科，不要脚手架志愿方案。

**不用 / 改走别的皮：**

| 需求 | 走哪条 |
|---|---|
| 霜蓝纸 + 右缘 28mm 通高涂布色条 + 魏碑 | `$eric-qingyun-frost-pdf`（H 霜蓝通缘） |
| 砂褐纸 + 四周 6mm 细框 + 框内朱印 | `$eric-qingyun-seal-pdf`（F 朱印砂卷） |
| 石灰纸 + 左 12mm 活页齿孔 | `$eric-qingyun-binder-pdf`（J 活页齿孔） |
| 新闻粗米 + 超粗黑头条 + 六栏 | `$eric-qingyun-news-pdf` |
| 整套客户 PDF 基线、雾蓝白案卷 | `$eric-qingyun-pdf` |
| 确认书、签发单、冷墨事务所 | `$eric-qingyun-cold-ink-pdf` |
| 出分后志愿冲稳保表、填报清单 | `$eric-qingyun-plan-pdf` / `$eric-qingyun-checklist-pdf` |
| 三人经营讨论稿、渠道返佣合同 | 不是这个家族 |

## 四硬差（家长一眼能分）

1. **对 H 霜蓝通缘：** 右缘是四枚错落下的半圆齿，**不是** 28mm 通高竖条。纸是军绿 `#8B9170`，不是霜蓝 `#C5D4E0`。
2. **对 F 朱印砂卷：** **无** 6mm 细框，**无** 朱砂方印。纸不是砂褐 `#C4A882`。全书隶书，不用楷体正文。
3. **对 J 活页齿孔：** **无** 左 12mm 打孔虚线与圆点。索引在右裁口，不在左。
4. **封面只露顶枚：** 封面右上只有一枚半圆，圆内写「青云」。内页才露出四枚（门 / 表 / 源 / 注），当前页那枚略大略深。

## 锁定 token

- 纸 `page fill`：`#8B9170`。半圆齿略深：`#6E7558`，当前页 `#4F563C`。
- 字：全书隶书 `Baoli SC` / `Libian SC`（报隶题、隶变文）。禁止楷、黑、宋做标题或正文。
- 右缘四枚半圆，直径约 14–16mm，圆心在右裁口，只露左半。
- 内页页脚：`青云` · `非正式官方文件 · 不保证录取` · 页码 `01`。封面可省略长页脚。
- 禁止印内部名「军绿指索」。

## 输入

最低输入（与共享案例字段对齐，见 `samples/facts.typ`）：

- 化名、省、年、批次（写「高一选科」，不要写本科批）
- 案例号、版本、日期
- 现行组合 / 备选组合 / 硬约束 / 软偏好 / 待补
- 科目门对照行（工科 / 医学 / 经管 / 放弃代价）
- 免责四句原文

没有当年官方来源的条目，标「待核验」，不得写成已核实事实。本册禁止院校冲稳保表，也不要印「冲稳保」三字。

## 怎么编译

需要 Typst 0.14.x，并确保 `typst` 在 `PATH` 中可用。

编本 skill 自带 4 页小样：

```bash
python3 scripts/compile_sample.py
```

编小样时脚本会带 `--root <skill-dir>`（小样 `#import "/theme.typ"`）。不要把 `samples/` 当 root。

新项目把 `theme.typ` 拷到稿件目录后：

```bash
typst compile document.typ document.pdf
```

新稿不要写进 skill 包。`#import "theme.typ": *`，`#show: thumb-doc.with(...)`（`qingyun-doc` 是别名）。封面用 `cover-page`，门表用 `gate-table`（开表，无填色、无勾选框）。拇指齿由 `thumb-index` 画在每页 background，几何锁在 `tab-centers` / `tab-d-quiet`。

自检：

```bash
python3 scripts/self_check.py
```

也可对任意 PDF：`python3 scripts/self_check.py --pdf <file.pdf>`。

## 禁词与文种边界

客户可见品牌只写「青云未来」。禁止出现：青云知路、青云志愿。

内部名「军绿指索」禁止出现在封面、页眉、页脚、正文、页码旁。

本季文种是选科指导报告。禁止做成志愿冲稳保院校表。也不要印「冲稳保」。

禁止：录取概率、上岸率、保证上岸、一定录取、公章、国徽。

每份客户稿必须有：署名「青云未来」、页脚「非正式官方文件 · 不保证录取」、免责四句、事实 / 判断 / 待核验。

免责四句原文锁定：

1. 本文件不是教育考试院或高校官方文件。
2. 本文件不构成录取、就业或薪资承诺。
3. 最终以当年官方系统、招生计划和高校招生章程为准。
4. 过期、缺失或相互冲突的数据，不得当作已核实事实。
