# Cinematic prompt pipeline

Use this pipeline only when a continuous visual journey materially improves the product. It generalizes an inspected workflow; it does not copy its brands, example subjects, prompts, media, or page compositions.

## Prompt 1 — divergent journey concepts

Give the creative agent:

- product truth, audience, and real content;
- subject, industry, material, or idea;
- frozen semantics and prohibited implications;
- target medium and viewport;
- any inspected references as observable rules plus explicit exclusions.

Ask for ten radically different concepts, not ten visual themes. Each concept must define:

- one continuous 8–10 second journey;
- starting scale and location;
- unbroken forward camera path;
- three or more materially different spatial events;
- physically legible material/light behavior;
- final reveal or resolved state;
- a product-specific reason for the journey;
- scroll-mapping notes, including any fixed payoff beat;
- a reverse-scrub risk;
- one interaction or navigation hook.

Do not request code or a finished page. Reject concepts that differ only by subject, color, or texture. Select three candidates with different spatial mechanics, then choose one after motion proofs or evidence.

## Prompt 2 — selected concept to production journey

Give the media/motion agent only the selected concept and production constraints. Require:

- a single unbroken shot with no editorial cuts;
- exact camera start, route, speed changes, lens behavior, and end frame;
- foreground, midground, and background parallax;
- material physics such as translucency, surface tension, refraction, grain, cloth, fluid, or particulate behavior when relevant;
- lighting direction, exposure progression, depth of field, and color transition;
- named event beats with approximate time or progress;
- sufficient ambient motion for reverse scrub not to look like a simple rewind;
- negative constraints: no logos, text, watermarks, arbitrary morphing, scene cuts, or unsupported product claims;
- target duration, aspect ratio, resolution, frame rate, and browser-delivery format.

If using generated video, generation, enhancement, or interpolation is a separate permission/cost boundary. Verify the output with media inspection. Never label a 30fps file as 60fps merely because interpolation was requested.

If using Canvas/WebGL/SVG/image sequences instead of video, keep the same shot contract and prove that the result has credible depth, occlusion, material response, and frame pacing. Label it as a procedural motion study rather than generated film.

## Prompt 3 — selected journey to website

Give the implementation agent:

- exact selected asset/source identity;
- the selected concept and event beats;
- product truth, content, CTA semantics, and prohibited implications;
- existing stack, components, tokens, and local assets;
- desktop, mobile, stress, and reduced-motion requirements.

Require:

- one sticky visual stage driven by one display-progress timeline;
- forward and reverse scrub;
- chapters mapped to actual scene events rather than equal scroll percentages;
- a compact guided tour plus manual scroll;
- minimal UI that never competes with the visual subject;
- typography and copy timed to visible safe zones;
- a real end state and honest CTA;
- mobile recomposition rather than cropping;
- a selected reduced-motion hero/state with equivalent information;
- resource, console, interaction, keyboard, and performance checks;
- immutable affected-candidate identity before review.

Do not include deployment credentials or publishing steps. Deployment is a separate authorization.

## Selection gates

Do not advance merely because the prompt or build completed.

1. Concept gate: three candidates differ in spatial mechanics and product fit.
2. Media gate: the selected journey has continuous depth, legible materials, and a usable end state.
3. Mapping gate: chapters and copy align with actual visual events.
4. Runtime gate: desktop/mobile/reduced-motion and forward/reverse behavior pass.
5. Review gate: substantial whole-screen work receives one fresh independent affected-candidate review.
