# v1.3.1 parent-feedback upgrade

Release date: 2026-08-25 (Asia/Shanghai)

This release preserves a concurrent, validated `eric-parent-feedback` upgrade on top of the v1.3.0 single-authority architecture.

## Changes

- Promotes `eric-parent-feedback` to 1.1.0 and the education collection to 1.2.0.
- Adds an evidence-calibrated editorial judgment pass, clearer source authority, severity, and prominence rules.
- Separates hard structural errors from style warnings, requires metadata before the first heading and non-empty section bodies, and scopes internal-label checks so legitimate technical lesson topics remain valid.
- Adds anonymized decision-based prompts and executable package tests.

The package remains independently installable and keeps the exact three-section parent-facing TXT contract. No private lesson, student, or family data is included.
