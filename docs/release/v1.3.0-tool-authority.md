# v1.3.0 tool authority

Release date: 2026-08-25 (Asia/Shanghai)

This release makes the GitHub checkout the write authority as well as the read authority for Eric Skills across local agent products.

## Built-in surfaces

- Shared-native discovery: Codex, Cursor, Kimi Code, OpenCode, Zed, and Roo Code read `~/.agents/skills`.
- Linked discovery: Claude Code, Hermes Agent, and Cline receive per-Skill links to the shared root.
- Configured discovery: Kimi Desktop keeps the shared root first in `extra_skill_dirs`.
- Higher-priority same-name copies are backed up before removal. Project-local overrides remain project-owned and are not mutated by the global synchronizer.

## Extensible surfaces

Machine-specific adapters live in `~/.config/eric-agent-skills/tool-surfaces.json` and never enter the public repository. Each entry uses one of two modes:

- `links`: populate a product-specific Skill root with links to the shared authority.
- `shadows`: preserve the product's native shared-root discovery while backing up same-name copies from its higher-priority root.

Both the registration helper and synchronizer accept only dedicated roots whose final path component ends in `skills`; they reject the filesystem root, home directory, shared root, repository checkout, duplicate or overlapping roots, malformed schemas, and unsupported modes. Registry validation completes before any reconciliation mutation.

Recursive shadow discovery never follows directory symlinks for mutation. A direct Skill symlink can be backed up safely as a link; a linked collection that exposes a managed Skill stops the entire reconciliation before any write and requires manual review.

## Creation and iteration

`eric-catalog` 1.1.0 now routes Skill creation and updates to the checkout first. New Skills must be added to `skills/`, the catalog, one collection, and product manifests before synchronization. Tool-specific discovery directories are never an editable upstream.

Publication remains explicit. No background updater or automatic GitHub push is enabled.
