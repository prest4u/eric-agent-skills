# v1.2.0 cross-agent version audit

Audit date: 2026-08-25 (Asia/Shanghai)

This release reconciles the Skill surfaces used by Codex, Kimi Code CLI, Kimi Desktop, Cursor, Claude Code, and Hermes Agent. The GitHub repository is the only editable authority; product-specific directories are discovery or installation surfaces.

## Selection rule

“Latest” means the newest **validated and publishable** implementation, not the newest filesystem timestamp. A candidate is rejected when it contains personal paths, private fixtures, undistributable reference assets, generated duplicate files, missing pinned dependencies, or a functional regression.

## Promoted updates

- `eric-soft-signal` 1.1.0: adopts the newer four-choice MCQ surface, layout checker, print-size floors, passage/task binding, and English-only cover-title font rules.
- Eighteen existing Eric Skills move to 1.0.1 for Chinese entry labels while preserving their portable implementation.
- Twenty-seven previously unmanaged Eric Skills enter the catalog at 1.0.0: the Eric catalog and workflow router, Teaching Deck, Web Pipeline, and twenty-three Qingyun document/visual workflows.
- Qingyun document extensions now carry their own visual, ethics, build, and QA baseline so each directory remains independently installable.
- Qingyun visual skins retain source templates and checks but omit generated PDF/PNG samples from the public package.

## Rejected wholesale candidates

Newer-looking local copies were not promoted wholesale when they reintroduced machine-specific paths, private validation corpora, undistributable screenshots or frontend bundles, removed pinned licensed references, weakened environment isolation, or dropped tests. Safe Chinese labels were merged into the current portable implementation instead.

## Release invariants

- Exactly 64 unique catalog Skills and 64 physical Skill directories.
- Every catalog Skill appears once in a metadata collection and once in the Claude marketplace manifest.
- Codex, Kimi, and Claude plugin manifests share one release version.
- Every `eric-*` description begins with Chinese text or a Chinese bracket label.
- Local synchronization backs up conflicts, removes higher-priority duplicates, and points every managed product surface to one checkout.
- No unattended background updater is installed; synchronization remains an explicit, inspectable action.

## Acceptance commands

```bash
python3 scripts/validate_repo.py
python3 -m unittest discover -s tests -v
python3 scripts/export_mirrors.py --check
python3 scripts/sync_user_install.py --check --json
```

Security scanning and independent release review are required before publication.
